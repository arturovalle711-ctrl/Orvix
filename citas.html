Flujo automático

De "quiero una cita" a "confirmado".

El proceso completo puede suceder dentro de una conversación.

01

El cliente solicita una cita

Puede hacerlo desde WhatsApp, un chatbot, una llamada u otro canal conectado.

02

Orvix consulta disponibilidad

El asistente identifica las opciones disponibles de acuerdo con las reglas establecidas.

03

El cliente elige

El usuario selecciona el horario que mejor se adapta a sus necesidades.

04

La cita queda confirmada

El sistema registra la reservación y puede iniciar automáticamente el flujo de confirmación y recordatorio.
